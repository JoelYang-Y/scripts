### `/etc/docker/daemon.json`（原文）

```json
{
  "registry-mirrors": [
    "https://oracle.jhsweetheart.com",
    "https://docker.1ms.run"
  ]
}
```

**要点**

- Alpine + `cgroupfs`：不要照搬 Debian 上的 `systemd` cgroup 配置，`/etc/docker/daemon.json` 里加 `"exec-opts": ["native.cgroupdriver=systemd"]` 会导致 dockerd 起不来。
- Alpine 无 bash，运维脚本一律用 `sh`；`docker compose` 是 v2 插件（`compose ls` 可用）。
- 该 VM 同时是 **DNS 唯一入口**：`53/tcp+udp`、`443`（DoH）、`80`（管理跳转）、`3000`（首次向导）都在 AdGuard 容器上，误停容器等于全屋断网解析。

## 3. 逐服务详解

### 3.1 adguardhome（DNS 入口 + 广告拦截）

- **用途**：局域网 DNS 入口，负责过滤、DoH/DoT 加密解析与查询日志；上游指向本机 PaoPaoDNS（5335）。
- **部署**：Compose 项目 `adguardhome`，项目路径 `/root/AdGuardHome/docker-compose.yml`，`restart: always`。
- **挂载**：`/root/AdGuardHome` **同时**挂到 `/opt/adguardhome/work` 与 `/opt/adguardhome/conf`（一个目录两处用，配置与规则同源）。
- **端口**：`53/tcp+udp`（DNS）、`80`（管理界面）、`443`（DoH）、`3000`（安装向导）。
- **要点**：
  1. 升级前必须 `cp AdGuardHome.yaml AdGuardHome.yaml.bak-$(date +%Y%m%d-%H%M%S)` —— schema 升级不可逆，回滚只能靠配置备份。
  2. 官方升级策略：稳定版可用即升；预发布线（`v1.0.0-b.*` / `v0.108.0-b.*`）不采用。
  3. `upstream_timeout` 曾评估从 1s 调到 2s，实测冷门域名递归 2–3.4s、PTR 反查 3.4s，调参救不回失败量，**维持 1s**。
  4. 443 端口同时是 DoH 入口与 PVE 侧可能的反代目标，改端口前先确认上游反代/证书链。
  5. 查询日志会持续增长，VM 仅 10 GB 盘，切日志前先看 `/root/AdGuardHome/data/querylog.json` 体积。

### 3.2 paopaodns（AdGuard 的上游解析器）

- **用途**：按国内外分流递归解析，把「干净结果」交给 AdGuard，AdGuard 只做过滤与缓存。
- **部署**：Compose 项目 `paopaodns`，路径 `/root/PaoPaoDNS/docker-compose.yml`，`restart: always`。
- **端口**：`5335:53`（被 AdGuard 作为上游引用）、`5304`、`7889`（Web/管理）。
- **关键环境**（与 NAS 实例的差异）：
  - `IPV6=yes_only6`：只处理 AAAA，A 记录交给国内链路 —— **不要**改成 `yes`，否则与 NAS 实例行为不一致。
  - `SOCKS5=@10.0.0.2:6153`：境外解析经 Mac mini 的 Surge SOCKS5 出口；Surge 关闭时境外域名会整体超时。
  - `CUSTOM_FORWARD_TTL=300`：转发结果缓存 5 分钟。
- **要点**：`/root/PaoPaoDNS` 整目录持久化；容器重建后若 DNS 异常，先确认 `SOCKS5` 指向的 Mac mini:6153 是否在监听。

## 4. 运维要点

1. **两跳解析链**：客户端 → AdGuard(53) → PaoPaoDNS(5335) → 上游/代理。任何一跳故障的表现都像"断网"，排障顺序按此链从后往前查。
2. **Alpine 无 bash**：所有脚本用 `sh`；`docker exec` 进容器同样没有 bash，只有 `sh`/`ash`。
3. **磁盘 10 GB**：Docker 镜像 + AdGuard 日志 + PaoPaoDNS 数据都在同一块盘，历史上出现过悬空镜像占满根分区（清理后可用空间才回到 300MB+），**升级后顺手 `docker image prune -f`**。
4. **证书**：DoH 依赖 443 上的证书，证书续期后需重启 `homelab-gateway` 或本容器的对应挂载方（见各自主机文档）。
5. **cgroupfs + Alpine**：PVE 侧若给 VM 改 CPU/内存热插，dockerd 不需要重启，但容器内 `nproc` 可能滞后，重容器即可。
