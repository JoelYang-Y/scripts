# Uptime Kuma 监控服务

## 1. 服务介绍
Uptime Kuma 是一款易用的开源自托管监控工具，能够帮助你实时监控服务运行状态。它支持丰富的监控类型（HTTP(s)、TCP、Ping、DNS、Docker 容器等）及多渠道告警通知，作为家庭 NAS 或私有云的第一梯队监控中枢非常合适。

## 2. 访问地址
- 仪表盘 Web 页面：[http://10.0.0.3:3005](http://10.0.0.3:3005)

## 3. 核心监控配置推荐（探针配置指南）

### 1) Sub-Store 订阅转换服务
- **监控类型**：HTTP(s)
- **URL**：`http://10.0.0.3:3002`
- **预期状态码**：`200`
- **说明**：监控代理订阅转换与过滤服务是否在线。

### 2) Emby 媒体服务器
- **监控类型**：HTTP(s)
- **URL**：`http://10.0.0.3:8096`
- **预期状态码**：`200`
- **说明**：监控影音服务器可用性，防止进程无响应。

### 3) 搬瓦工 VPS 与节点连通性
- **监控类型**：TCP 端口 或 Ping
- **主机名/IP**：VPS 公网 IP
- **端口**：SSH 端口 (59421) 或节点监听端口
- **说明**：实时掌握远程 VPS 主机与代理端口的连通性。

### 4) AT&T 美国家宽出口监测
- **监控类型**：TCP 端口 / Ping
- **主机名/IP**：`107.141.151.219`
- **说明**：监控美国家宽出口连通状态。

### 5) 核心 DNS 链路解析
- **监控类型**：DNS 记录
- **解析服务器**：`10.0.0.6` (PaoPaoDNS / AdGuard Home)
- **解析域名**：`www.apple.com` 或 `www.google.com`
- **说明**：确认家庭网络防污染 DNS 链条解析正常。

## 4. Telegram 告警配置指南

1. **申请机器人 Token**：在 Telegram 搜索 `@BotFather`，创建机器人获取 `Bot Token`。
2. **获取 Chat ID**：在 Telegram 搜索 `@userinfobot` 获取个人的 `Chat ID`。
3. **在 Uptime Kuma 绑定**：
   - 打开设置面板 -> 进入「通知」菜单。
   - 点击「设置通知」，通知类型选择 `Telegram`。
   - 填入 `Bot Token` 与 `Chat ID`。
   - 点击「测试」，收到通知后保存即可。
