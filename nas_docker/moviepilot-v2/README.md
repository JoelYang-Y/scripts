# MoviePilot-v2 - 影视自动化中枢

MoviePilot 是新一代的自动化观影管理中枢，支持 PT 站点自动签到、订阅追剧、自动下载、文件自动整理刮削、硬链接入库以及媒体服务器（Emby）通知同步。

## 端口与访问 (Host 模式)

- **Web 管理界面**: `http://<NAS_IP>:3000` (默认端口 3000)
- **初始账号密码**: 首次运行由系统生成或在后台初始化

## 目录结构

```text
moviepilot-v2/
├── docker-compose.yml
├── config/                # 配置文件、站点认证凭据及插件
├── core/                  # Playwright 浏览器内核持久化缓存
└── /media                 # 媒体库挂载点 (下载与入库需在同一存储卷以支持秒级硬链接)
```

## 硬链接 (Hardlink) 核心原则

- **必须位于同一存储池/文件系统**: 下载目录 `/media/download` 和媒体库目录 `/media/movies` 必须在同一个挂载点下，才能实现 0 磁盘占用的硬链接入库。
